# Yastık Altı Kumanda Arkeolojisi

TentiAŞ Yastıkaltı Kazı Dairesi'nin resmi, gereksiz ve çalışır enstitüsü.

Kumanda kaybolmaz. Kumanda **gömülür**. Yastık bir sit alanıdır. Koltuk dikişi stratigrafidir. Kırıntı tabakası Geç Akşam Çağı'na aittir.

Bu depo, kayıp kumandayı katman katman kazan bir Python kazısıdır. Pil biterse suç arkeoloğa yazılır. Suç koltuğa yazılmaz. Koltuk tanıktır, ifade vermez.

## Neden var

Çünkü biri "kumanda nerede" dedi ve oda bir kazı alanına döndü. Diğer depolar priz, turnike, kargo notu ve asansör suskunluğu ile meşgul. Bu depo onların hiçbiri değil. Bu depo yastığın altını milletlerarası kazı sahası sanır.

Patates içermez. Bilimsel gerekçe: patates yuvarlanır, kumanda kaybolur. Ayrı dosyadır.

## Kurulum

Python 3 yeter. Bağımlılık yoktur. Medeniyet de yoktur.

```bash
python kazi.py
python kazi.py --katman 7
python kazi.py --tohum 42
```

## Katmanlar

1. Üst yastık kılıfı (Geç Çarşaf)
2. Ekmek kırıntısı alüvyonu
3. Kayıp çorap tekili (eşi başka evrendir)
4. Eski fiş, yeni umut
5. Kumanda. Bazen. Genelde bir katman daha.

## Lisans

Kumandayı bulan kullanır. Bulamayan kanalı ezberler.
